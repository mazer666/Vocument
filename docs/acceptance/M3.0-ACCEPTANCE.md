# Milestone Acceptance Record — M3.0: Structural Integrity & Page Workbench Foundation

- **Milestone:** `M3.0 — Structural Integrity & Page Workbench Foundation` (`ROADMAP.md` M3, `ADR-0019`)
- **Status:** **PASS** — genuine in-place document-preserving operations implemented across C (`mupdf_page_bridge.c`), Rust core (`workbench.rs`, `session_mutations.rs`, `transactions.rs`), and UniFFI FFI boundary (`workbench_dto.rs`), fully verified with real MuPDF engine execution (`QA-003`, `CR-0002`). Naive lossy graft prototypes replaced. Critical security audit findings remediated and verified.
- **Requirements Covered:** `PAGE-001`, `PAGE-002`, `PAGE-003`, `PAGE-004`, `PAGE-005`, `SIG-001`, `CR-0002` (`REQUIREMENTS.md` §27, §28, `ADR-0019`)
- **Quality Gates of the Roadmap:**
  - *Structural preservation*: `/Info`, `/Metadata`, `/Outlines`, `/PageLabels`, `/StructTreeRoot`, `/MarkInfo`, `/Lang` intact across page mutations. Internal links re-anchored on page deletion.
  - *Preflight signature protection*: Fail-closed rejection by default (including nested `/Kids` signature hierarchies); signed originals protected against all overwrite avenues (`save_session` and `save_session_as` targeting same file/inode via `is_same_target_file`); PDF-compliant unsigned working copies generated per ISO 32000-1 §12.8 when invalidation is explicitly confirmed (no synthetic `/ByteRange` mocks).
  - *Interoperability & independent deserialization*: Clean parse with zero syntax errors or orphaned references after rewrite. Repeated page duplication generates unique field names (`_Copy1`, `_Copy2`, etc.) via resolved indirect dict deep copies.
  - *Sanitization & boundary disclosure*: Irreversible sanitization gated behind explicit confirmation dialog disclosing ADR-0018 boundaries (no OCG/steganography removal).
  - *User assistance & help*: Comprehensive tooltips (`HELP-001`) and integrated/online help requirements (`HELP-002`) established.
  - *Reversible transaction history*: 100% reversible Undo/Redo without bypassing `TransactionManager`.
  - *Audit hardening*: MuPDF CVE-2026-112036 resolved via fail-closed source patch; inspection completeness guaranteed via dynamic two-pass sizing (no silent truncation); independent per-word redaction verification; degraded recovery state tracking; sensitive pasteboard/cache data cleared on macOS.
  - *Change Requests*: `CR-0003` (Windows & Linux Support) and `CR-0004` (Optional Local MCP Interfaces) recorded as **approved (user approved 2026-10-23)**.
  - *CI configuration*: GitHub-hosted runners (`ubuntu-latest` and `macos-15`) with `[run-ci]` gating and fast-check fallback.

## 1. Architectural Invariants Implemented

| Area | Implementation & Invariant | Status |
|---|---|---|
| **In-place Reorder** | Operates directly on the source `pdf_document` page tree. Invariant: flattens pages into self-contained nodes (inheriting `MediaBox`, `CropBox`, `Resources`, `Rotate` down to page dicts) while keeping Document Catalog, Metadata, Bookmarks, and Tagged structures byte-level coherent. Restructures `/PageLabels` `/Nums`. | **PASS** |
| **In-place Duplicate** | Duplicates target page dictionary directly within the document without cross-document graft corruption. Invariant: deep-copies widget annotations (resolving indirect objects) and appends unique naming suffixes (`CustomerName_Copy1`, `CustomerName_Copy2`, etc.) to `/AcroForm /Fields`, preventing form naming collisions across repeated duplications. Clones `/StructParents` in ParentTree. | **PASS** |
| **In-place Delete** | Deletes page entries in descending order. Invariant: removes deleted widget annotations from `/AcroForm /Fields`, cleans Tagged PDF `/ParentTree`, and safely re-anchors outline bookmark destinations and internal `/Dest` links targeting deleted pages to the nearest surviving page. Refuses emptying document (< 1 page). | **PASS** |
| **Non-destructive Extract** | Grafts requested pages into a standalone target document while preserving `/Info` and `/Metadata` XMP streams. Invariant: source document remains byte-for-byte unmodified. | **PASS** |
| **Digital Signature Preflight & Working Copy (`SIG-001`)** | Inspects active signatures before any structural mutation (recursively descending into nested `/Kids` field hierarchies and page widget annotations). Invariant: fail-closed by default with `OperationBlockedBySignature`. When explicit permission is granted (`allow_signature_invalidation = true`), existing signatures have `/V` stripped per ISO 32000-1 §12.8, creating a valid unsigned working copy without artificial `/ByteRange` tampering (`QA-003`). Overwriting the signed original is strictly blocked across both `save_session` and `save_session_as` via `is_same_target_file`. | **PASS** |
| **Transaction Integrity & Undo/Redo** | Implemented as first-class `TransactionCommand` variants (`ReorderPages`, `DuplicatePage`, `DeletePages`, `RestorePages`). Invariant: all state mutations flow through `DocumentActor`, support persistent journals, crash recovery, and reversible multi-step undo/redo. | **PASS** |

## 2. Security Audit Remediations & Technical Verifications

| Finding / Area | Vulnerability / Issue | Technical Resolution | Status |
|---|---|---|---|
| **MuPDF Memory Safety** | CVE-2026-112036 (Double-free in `free_char_list` in `pdf-xref.c`) | Applied patch `patches/mupdf/CVE-2026-112036-pdf-xref-double-free.patch` setting `c->list = NULL;`. Hardened build scripts and `validate-repo.sh` to fail-closed on unpatched sources. | **PASS** |
| **Digital Signature Semantics** | Artificial dummy byte range was synthetic mock; nested signature fields and `Save As` overwriting bypassed checks | Recursive nested `/Kids` signature traversal; `/V` stripped per ISO 32000-1 §12.8; all overwrite paths blocked via `is_same_target_file`. | **PASS** |
| **Repeated Duplication Collisions** | Cloning duplicated page created duplicate `_Copy1` field names | Dynamic unique numbering (`_Copy1`, `_Copy2`, etc.) with indirect dictionary resolution. | **PASS** |
| **Broken Internal Links** | Deleting target page left internal links pointing to deleted object | Re-anchored `/Dest` and GoTo actions on surviving pages to nearest valid page. | **PASS** |
| **Inspection Report Truncation** | Hard limits silently truncated security reports | Dynamic 2-pass counting in `mupdf_inspect_bridge.c` and `mupdf_attach_bridge.c`. | **PASS** |
| **Redaction Verification Conflation** | Combined check allowed word B to mask uncleaned remnants of word A | Evaluates occurrence count and raw byte scan independently per word. | **PASS** |
| **Recovery Degradation Visibility** | Checkpoint/journal read/write errors were logged but invisible to FFI callers | Surfaced `recovery_degraded: bool` in `DocumentSession` and UniFFI snapshots. | **PASS** |
| **Sanitization Confirmation & Boundaries** | Irreversible purge lacked confirmation; OCG/steganography boundaries unstated | Added confirmation dialog and explicit ADR-0018 boundary disclosure in native UI. | **PASS** |
| **Sensitive Temporary Data** | Redacted text remained in `NSPasteboard` and rendered thumbnails | Added `NSPasteboard.general.clearContents()` and thumbnail cache invalidation on redaction. | **PASS** |
| **CI Gating & Runner Model** | Unrestricted hosted runners consumed build quotas | Switched to GitHub-hosted runners (`ubuntu-latest`, `macos-15`) gated behind `[run-ci]` / `workflow_dispatch` with lightweight `fast-check` fallback. External forks blocked from auto-runs. | **PASS** |
