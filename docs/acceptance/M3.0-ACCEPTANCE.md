## 1. Architectural Invariants Implemented

| Area | Implementation & Invariant | Status |
|---|---|---|
| **In-place Reorder** | Operates directly on the source `pdf_document` page tree. Invariant: flattens pages into self-contained nodes (inheriting `MediaBox`, `CropBox`, `Resources`, `Rotate` down to page dicts) while keeping Document Catalog, Metadata, Bookmarks, and Tagged structures byte-level coherent. | **PASS** |
| **In-place Duplicate** | Duplicates target page dictionary directly within the document without cross-document graft corruption. Invariant: deep-copies widget annotations and appends unique naming suffixes (e.g. `CustomerName_Copy1`) to `/AcroForm /Fields`, preventing form naming collisions. | **PASS** |
| **In-place Delete** | Deletes page entries in descending order. Invariant: removes deleted widget annotations from `/AcroForm /Fields` and safely re-anchors outline bookmark destinations targeting deleted pages to the nearest surviving page. Refuses emptying document (< 1 page). | **PASS** |
| **Non-destructive Extract** | Grafts requested pages into a standalone target document while preserving `/Info` and `/Metadata` XMP streams. Invariant: source document remains byte-for-byte unmodified. | **PASS** |
| **Digital Signature Preflight & Working Copy (`SIG-001`)** | Inspects active signatures before any structural mutation. Invariant: fail-closed by default with `OperationBlockedBySignature`. When explicit permission is granted (`allow_signature_invalidation = true`), existing signatures have `/V` stripped per ISO 32000-1 §12.8, creating a valid unsigned working copy without artificial `/ByteRange` tampering (`QA-003`). In-place save is strictly forbidden (`save_session` blocks with `SignedOriginalOverwriteBlocked`), requiring "Save As". | **PASS** |
| **Transaction Integrity & Undo/Redo** | Implemented as first-class `TransactionCommand` variants (`ReorderPages`, `DuplicatePage`, `DeletePages`, `RestorePages`). Invariant: all state mutations flow through `DocumentActor`, support persistent journals, crash recovery, and reversible multi-step undo/redo. | **PASS** |

## 2. Security Audit Remediations & Technical Verifications

| Finding / Area | Vulnerability / Issue | Technical Resolution | Status |
|---|---|---|---|
| **MuPDF Memory Safety** | CVE-2026-112036 (Double-free in `free_char_list` in `pdf-xref.c`) | Applied patch `patches/mupdf/CVE-2026-112036-pdf-xref-double-free.patch` setting `c->list = NULL;` on deallocation. Integrated into `prepare-host-mupdf.sh` and `prepare-android-mupdf.sh`. | **PASS** |
| **Digital Signature Semantics** | Artificial dummy byte range `[0, 1, 2, 3]` was synthetic mock and caused MuPDF EOF parsing errors | Removed dummy range; cleanly delete `/V` per ISO 32000-1 §12.8, creating PDF-compliant working copy. In-place overwrite of signed original blocked in `save_session`. | **PASS** |
| **Inspection Report Truncation** | Hard limits (512 actions / 256 attachments / 64 signatures) silently truncated security reports | Implemented two-pass dynamic counting in `mupdf_inspect_bridge.c` and `mupdf_attach_bridge.c`; fail-closed status 3 if capacity exceeded. | **PASS** |
| **Redaction Verification Conflation** | Combined word check allowed remaining occurrences of word B to mask uncleaned remnants of word A | Refactored `redaction.rs` to evaluate occurrence count and raw byte scan independently per word. | **PASS** |
| **Recovery Degradation Visibility** | Checkpoint/journal read/write errors were logged but invisible to FFI callers | Surfaced `recovery_degraded: bool` in `DocumentSession`, `DocumentSessionSnapshot`, and `FfiDocumentSessionSnapshot`. | **PASS** |
| **Sensitive Temporary Data** | Redacted text remained in `NSPasteboard` and rendered thumbnails | Added `NSPasteboard.general.clearContents()` and thumbnail cache invalidation in macOS `ReviewWorkflow.swift`. | **PASS** |
| **CI Gating & Runner Model** | Unrestricted hosted runners consumed build quotas | Switched to GitHub-hosted runners (`ubuntu-latest`, `macos-15`) gated behind `[run-ci]` / `workflow_dispatch` with lightweight `fast-check` fallback. External forks blocked from auto-runs. | **PASS** |
