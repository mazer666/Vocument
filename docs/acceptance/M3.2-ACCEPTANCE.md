# Milestone Acceptance Record — M3.2: Multi-Document Operations (Merge, Insert & Split)

- **Milestone:** `M3.2 — Multi-Document Operations: Merge, Insert & Split` (`ROADMAP.md` M3, `ADR-0019`)
- **Status:** **PASS** — Comprehensive native multi-document operations fully implemented across C bridge (`mupdf_multidoc_bridge.c`), Rust engine (`multidoc_ops.rs`, `multidoc_tests.rs`), Core transaction manager (`transactions.rs`, `session_mutations.rs`), UniFFI export layer (`workbench_dto.rs`), and native macOS AppKit/SwiftUI interface (`WorkbenchWorkflow.swift`, `PageWorkbenchView.swift`). Real MuPDF execution with zero stubs or dummy returns (`QA-003`, `CR-0002`).
- **Requirements Covered:** `PAGE-006`, `PAGE-007`, `PAGE-008`, `SIG-001`, `UNDO-001`, `UNDO-004`, `HELP-001`, `UI-010` (`REQUIREMENTS.md` §27, §28, `ADR-0019`)
- **Quality Gates of the Roadmap:**
  - *Native page grafting*: Multi-document page grafting via `pdf_graft_mapped_page` with shared graft mapping (`pdf_graft_map`) ensuring automatic resource deduplication (fonts, XObjects, color spaces).
  - *Merge multiple PDFs*: Merges $N$ documents in specified sequence, unifying page catalogs, re-anchoring outline bookmark hierarchies (`append_grafted_outlines`), and shifting logical page labels (`append_grafted_pagelabels`).
  - *Insert external pages*: Inserts selected page subsets from external PDFs at arbitrary 0-based insertion points, cleanly shifting surviving page label ranges (`shift_existing_pagelabels`).
  - *Form field collision resolution*: Merged and inserted interactive form widgets are mapped into the target `/AcroForm /Fields` array with automatic collision detection and deterministic unique suffix renaming (`merge_acroform_fields_for_grafted_page`).
  - *Split document*: Splits document into separate standalone PDF buffers by custom partitions, page selections, or individual single pages with independent valid catalogs and xref tables.
  - *Fail-closed signature guard*: Any merge or insert involving signed documents strictly fails-closed (`OperationBlockedBySignature`) unless explicit user invalidation is approved per ISO 32000-1 §12.8.
  - *Traceable Undo/Redo*: Merges and insertions execute through `TransactionManager` as `TransactionCommand::MergeDocuments` and `TransactionCommand::InsertPagesFromDocument` with exact `RestorePages` byte-preservation rollback.
  - *Native macOS UX*: Ergonomic toolbar controls ("Insert…", "Merge…", "Split…") integrating native `NSOpenPanel` / folder pickers and plain-language tooltips.
