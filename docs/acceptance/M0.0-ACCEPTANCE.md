## 4. Usability

- task step count: 1 command (`make check`) to validate, build, regenerate/verify bindings, and run cross-platform handshakes
- discoverability notes: `README.md`, `WHERE_TO_CHANGE.md`, and `Makefile` (`make help`) provide immediate onboarding for coding beginners
- mobile/native behaviour: `apps/macos` uses SwiftUI + AppKit (`CalmReaderBootstrapView`); `apps/android` uses Jetpack Compose with `Pages / Search / Tools` compact bottom navigation (`MinimalReaderBootstrapScreen`)

## 5. Accessibility

- keyboard: standard SwiftUI/AppKit and Material3 Compose focus primitives in bootstrap shells
- VoiceOver/TalkBack: semantic text labels used in both bootstrap views
- scaling/high contrast: dynamic system theme (`theme = "system"`) configured in `config/app-defaults.toml`

## 6. Security/privacy

- new data stored: none
- network access: none (`network.default_policy = "deny_all"` enforced by `SecurityPolicyConfig::validate_invariants`; `AndroidManifest.xml` declares zero network permissions)
- negative tests: `SecurityPolicyConfig::validate_invariants` rejects any config where `default_policy != "deny_all"`, `enable_telemetry == true`, `enable_automatic_crash_upload == true`, or `treat_all_inputs_as_untrusted == false`

## 7. Interoperability/data integrity

- reopen in Vocument: N/A for M0.0 (starts in M0.1)
- external viewers/editors: N/A for M0.0
- roundtrip: UniFFI contract version (`29`) and API checksum (`document_core_handshake`) verified across Rust, Swift, and Kotlin
- recovery/save integrity: N/A for M0.0

## 8. Known limitations

- Full Xcode.app (`xcodebuild`) and full Android SDK/NDK APK packaging are optional on developer machines that only have Command Line Tools + OpenJDK/Kotlin CLI installed; `swift build`/`swift run` and `kotlinc`+JNA verify the exact Swift and Kotlin UniFFI sources headlessly in `local-ci.sh`.
- GitHub Actions workflow (`.github/workflows/ci.yml`) is configured for `runs-on: self-hosted`; until a self-hosted runner daemon is registered for `mazer666/Vocument`, all CI checks are enforced locally via `.git/hooks/pre-push` and `./scripts/local-ci.sh`.
