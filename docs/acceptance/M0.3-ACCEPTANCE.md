## 4. Six-Dimensional Quality Gate Summary (`QUALITY.md`)

1. **Functional Correctness:** All 19 Rust workspace unit & integration tests, macOS Swift CLI, and Android Kotlin CLI pass end-to-end.
2. **Performance & Responsiveness:** Classic FTS5 search completes in `< 1 ms`; thumbnails use a dedicated LRU `ThumbnailCache` at `JobPriority::Thumbnails` (`5`) so viewport tiles are never evicted by thumbnail scrolling.
3. **Architecture & Boundary Integrity:** Zero direct MuPDF or SQLite calls in `apps/macos` or `apps/android`; all state flows through `vocument-core` and UniFFI.
4. **Security & Privacy:** Strictly offline (`NET-001`), zero telemetry (`LOG-001`), safe C bridge (`fz_try`/`fz_catch`) with bounded buffers.
5. **UX & Accessibility:** Both physical page numbers (`#1..#N`) and logical page labels (`i, ii, 1, 2`) are displayed side-by-side (`PAGELABEL-002`); both cleaned plain-text copy (`OCRCOPY-002`) and raw copy (`OCRCOPY-001`) are exposed.
6. **Documentation & Governance:** Documented in `ADR-0006`, `M0.3-ACCEPTANCE.md`, `ROADMAP.md`, `THIRD_PARTY.md`, and `CHANGELOG.md`.
