# Milestone Acceptance Record — M3.3: Page Geometry, Crop & Deskew

- **Milestone:** `M3.3 — Page Geometry, Crop & Deskew` (`ROADMAP.md` M3, `ADR-0019`)
- **Status:** **PASS** — Complete native implementation of millimeter-accurate page boundary calibration for all 5 ISO 32000-1 boxes, non-destructive display crop, destructive content-clipping hard crop, automatic deskew angle detection with fine transformation matrix rotation, auto-crop margin trimming, reversible transactions in `TransactionManager`, and cross-platform native bindings. Executed natively with zero stubs or mock simulations (`QA-003`, `CR-0002`).
- **Requirements Covered:** `CROP-001`, `CROP-002`, `CROP-003`, `ROTATE-001`, `ROTATE-002`, `ROTATE-003`, `SIG-001`, `UNDO-001`, `HELP-001`, `UI-010` (`REQUIREMENTS.md` §27, §28, `ADR-0019`)
- **Quality Gates of the Roadmap:**
  - *All 5 ISO 32000-1 page boxes*: Queries and calibrates `MediaBox`, `CropBox`, `BleedBox`, `TrimBox`, and `ArtBox` with millimeter-accurate precision (represented in 1/1000 point milli-pt integers).
  - *Display Crop vs Hard Crop*: Non-destructive display crop updates `/CropBox` in the page dictionary preserving raw streams; destructive hard crop injects clipping path operators `q x y w h re W n ... Q`, clamps `MediaBox` and `CropBox`, shifts coordinates to origin, and prunes out-of-bounds annotations.
  - *Automatic deskew angle detection*: Real-time Radon/projection variance search across $[-15^\circ, +15^\circ]$ (coarse $0.5^\circ$, fine $0.1^\circ$ resolution) with safe zero-angle fallback for uniform or blank pages.
  - *Fine deskew rotation*: Injects affine transformation matrix `cm` into content stream without lossy rasterization, adjusting page geometry and reversing text orientation.
  - *Auto-crop margin trimming*: Border luminance scanning with configurable safety margin (default 5 mm) bounded to `MediaBox`.
  - *Fail-closed signature preflight*: Modifying page boundaries, clipping streams, or injecting deskew matrices strictly fails-closed (`OperationBlockedBySignature`) unless explicit signature invalidation is user-confirmed.
  - *Reversible Undo/Redo*: All operations execute through `TransactionManager` as `SetPageBoxes`, `ApplyHardCrop`, `DeskewPages`, and `AutoCropPages` with byte-preserving `RestorePages` rollback.
  - *Native UI Integration*: macOS SwiftUI toolbar buttons ("Crop…", "Deskew") and dedicated modal `CropSheetView` (Presets: A4, Letter, Auto-Crop Margins, Custom).
