## 2. Roadmap Gate Verification (`ROADMAP.md` line 147)

> **Gate:** *Nie still extern geänderte Inhalte überschreiben.* (Never silently overwrite externally changed content.)

- **Automated Verification:**
  1. **Strict Core Guard:** In `SaveCoordinator::execute_safe_save` (`core/vocument-core/src/save.rs`), before staging or committing any data to disk, the target file's identity is inspected via `FileBroker::inspect_file_identity`. If `FileIdentityComparison::ModifiedExternally` or `DifferentFileReplacingSamePath` is detected and `!allow_overwrite_external`, the coordinator aborts save immediately, discards any temporary staging data, leaves the target file untouched, and returns `SaveResult::Conflict`.
  2. **Automated Integration Test:** `core/vocument-core/tests/safe_save_tests.rs`: `test_gate_never_silently_overwrites_externally_changed_content` creates an external file modification, attempts `save_session()`, and asserts that:
     - `SaveResult::Conflict` is returned.
     - The on-disk file content remains byte-for-byte identical to the external modification.
     - The local unsaved session remains dirty (`is_dirty == true`).
  3. **End-to-End Handshakes:**
     - **Swift (`apps/macos/Sources/VocumentMacHandshakeCLI/main.swift`):** Simulates external write on disk, executes `saveSession()`, verifies `FfiSaveOutcome.conflict` with safe copy recommendation, and confirms original external content is preserved untouched.
     - **Kotlin (`apps/android/app/src/test/java/org/vocument/app/VerifyKotlinHandshakeCli.kt`):** Simulates external write, calls `saveSession()`, confirms `FfiSaveOutcome.Conflict`, and verifies external file integrity is maintained.
