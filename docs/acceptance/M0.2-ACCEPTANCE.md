## 4. Concrete Entry Point for M0.3 — Navigation, Search, Selection

With M0.2 complete, the next milestone (`ROADMAP.md` lines 97–123) is **M0.3 — Navigation, Search, Selection**:
1. Extend `PdfEngine` & `engines/pdf-mupdf` to extract document outline/TOC (`OutlineNode`), structured page text + glyph/selection quads, and low-resolution page thumbnails (`JobPriority::ThumbnailGeneration`).
2. Add SQLite FTS5 incremental full-text search index inside `vocument-core` (`JobPriority::IncrementalSearchIndex`) returning page hits and highlight bounding boxes.
3. Expose outline, page go-to, text selection/copy, and FTS5 search queries across `platform/vocument-ffi` to macOS and Android UI.
