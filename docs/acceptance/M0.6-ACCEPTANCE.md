## 2. Roadmap Gate & Destructive Test Verification (`ROADMAP.md` lines 162–171)

> **Required destructive test:**
> 1. open document
> 2. make unsaved edit
> 3. hard-kill process (`SIGKILL`)
> 4. restart
> 5. detect recovery
> 6. preview/restore
> 7. confirm original remains intact until explicit save

- **Subprocess SIGKILL Test (`core/vocument-core/tests/recovery_tests.rs`):**
  - Spawns a child process of the test executable (`VOC_TEST_RUN_CRASH_VICTIM=1`).
  - Child opens PDF document, applies unsaved rotation transaction, writes recovery journal, and notifies parent via readiness signal file.
  - Parent process immediately sends `child.kill()` (`SIGKILL` on macOS/Unix), terminating the child mid-session without running destructors or clean shutdown handlers.
  - Parent re-opens `RecoveryStore`, detects unclean shutdown (`!is_clean_shutdown && has_unsaved_changes`).
  - Asserts that original on-disk PDF remains 100% byte-for-byte identical to baseline SHA-256.
  - Executes `Restore` action: journals and checkpoints replayed into fresh session; dirty flag is preserved.
  - Asserts again that on-disk PDF remains untouched until explicit save.
  - Finally performs explicit `save_session()`, verifying atomic commit and clean shutdown marking.
- **End-to-End Swift & Kotlin Handshakes:**
  - **Swift (`apps/macos/Sources/VocumentMacHandshakeCLI/main.swift`):** Mutates session, scans recovery containers, checks recovery for source path, asserts disk bytes remain identical, executes Restore, confirms disk file remains untouched.
  - **Kotlin (`apps/android/app/src/test/java/org/vocument/app/VerifyKotlinHandshakeCli.kt`):** Executes full recovery detection, verifies gate invariant (disk bytes untouched), executes Restore, confirms original bytes intact.
